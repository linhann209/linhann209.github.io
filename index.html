Featured prototype

Engineering and Maintenance Knowledge Assistant

The prototype explores how engineering and maintenance teams can find and connect information across manuals, safety procedures, technical guidance, and maintenance history.

It demonstrates evidence retrieval, structured guidance, source citations, focused follow up, conversation history, and refusal when the available sources do not support an answer.

Read the case study View the public code

Current demonstration

The public version uses synthetic sources and a transparent local simulation. It demonstrates interaction and control design rather than production engineering accuracy or live model performance.

Production direction

The intended solution combines authorized enterprise sources, exact and semantic retrieval, governed LLM reasoning, citations, deterministic controls, and qualified human review.

System relationship

The assistant is designed to complement existing knowledge and document systems. Authoritative records, permissions, revisions, and governed actions remain in their systems of record.

AI decision support prototype

AI Opportunity Assessment

This tool applies the Value versus Complexity framework to assess whether an existing business process is suitable for an AI experiment.

It combines transparent scoring with evidence, consequence, and accountability safeguards, then recommends the next responsible action. When a prototype is justified, it defines a bounded experiment and shows how the proposed AI capability could improve the process.

Read the article View the public code

Transparent assessment

Value and Complexity remain separate, while evidence, consequence of error, and human accountability are evaluated as explicit safeguards.

Defined AI role

Deterministic logic calculates scores and conditions. AI supports process interpretation, follow-up questions, explanations, and future process design.

Responsible next step

The tool recommends a bounded experiment only when the evidence supports it. Potential benefits remain testable reference scenarios, not confirmed ROI.
